# 재현 절차 (로컬 실행 기준)

작성 기준: 2026-11-11, 브랜치 `feat/approval-flow`. 아래 명령은 모두 이 저장소 루트에서 실행했을 때의 동작입니다. **배포 주소에서의 재현은 아직 하지 못했습니다**(맨 아래 "현재 제약" 참고).

## 1. 준비
| 항목 | 내용 |
|---|---|
| 도구 | Node 24, npm 11 (TypeScript 5, Vitest 3, Next.js 15.5.29, React 19, PGlite 0.5.16) |
| 설치 | `npm ci` |
| 원본 데이터 | `01_참가자_배포용/04_원본데이터` (읽기 전용). 다른 위치는 환경변수 `DATA_DIR`로 지정 |
| DB | 로컬·테스트는 내장 메모리 Postgres(PGlite)라 설정이 필요 없음. 운영은 `DATABASE_URL`(PostgreSQL) 필수 |
| AI | 선택. `ANTHROPIC_API_KEY`가 없으면 규칙 기반 템플릿 + "AI 미사용" 표시 |


## 4. 시연 3건 — 스크립트
```bash
npm run demo -- all        # 또는 normal | change | shortage
```
시나리오마다 처음부터 초기화하고, 단계별 로그와 확인 값을 출력합니다.

## 5. 시연 3건 — 화면
```bash
npm run dev                # http://localhost:3000 (개발 모드, 메모리 DB)
```
상단에서 **역할을 전환**하며 진행합니다(로그인 없음). 시작 전 `가정·기준값` 화면의 "전체 초기화"를 누르면 업무 시계 2026-07-01, 26건 `재무 확인 대기`로 돌아갑니다.

| 사례 | 입력과 순서 | 확인할 것 |
|---|---|---|
| 정상 | 첫 화면(`오늘 결정할 것`)을 연다 | 26건, 하회 구간 배너 `2026-07-21 ~ 2026-08-21`, CEO/이사회 13건·대표+그룹 보고 13건, LOSS 이슈 6개 캠페인, 확정 전 집행 예정 12건, 혜인 전속계약 상세에 "이사회 2026-07-06" |
| 변경 (모의) | `CONTRACT-INF-001` 상세 → "모의 입력: 고정 피 조건 변경"에 `1800000000` 제안 → 초기화 후 `900000000` 제안 → `확인 요청함`에서 "유리한 회신(9/30)" 또는 "불리한 회신(8/10)" 버튼 | 18억: CEO/이사회 유지, 위약금 표시. 9억: 대표 승인으로 내려가고 현금 유출일 확인 요청 생성, 회신 8/10 → CEO/이사회, 9/30 → 대표. `가정·기준값`에서 LC-0001 45일로 바꾸면 하회 구간이 사라지고 CEO/이사회는 전속계약 1건만 남음 |
| 정보 부족·거절 | 역할 `Masil 재무팀`으로 전속계약 "재무 확인" → 역할 `마케팅 담당`으로 "상신" → 역할 `CEO/이사회`로 "보류"(필요한 정보·담당·기한 입력) → `가정·기준값`에서 시계를 `2026-07-14`로 진행 → 건 상세 → `확인 요청함`에서 유리/불리/지연 회신 | 보류는 담당·기한 없이 제출되지 않음. 7/14에 D-3 에스컬레이션과 선택지 3개(조건 변경 통보 / 해지 통보 / 상신 후 승인). 회신 후 재계산·재판정, 지연 회신은 보류 유지. 별도로 CEO/이사회가 "거절" → 마케팅이 "재상신". 혜인 기안(PLAN-001)만 거절하면 "기안만 부결, 계약은 자동 갱신" 경고 |

모든 모의 입력·회신은 화면과 이력에 "모의"로 표시됩니다. 업무 시계는 되돌릴 수 없으며, 다시 하려면 초기화합니다.

## 6. 결과를 확인하는 위치
- 건 상세의 `이력` 표: 업무일, 행위자, 행위, 근거, 가정 버전, 모의 여부
- `확인 요청함`: 담당·기한이 붙은 요청과 처리된 요청
- 첫 화면: 상태, 경로, 기한 카운트다운, 연결 그룹 경고

## 7. 재실행 전 초기화와 현재 제약
- 초기화: `가정·기준값` 화면의 "전체 초기화"(또는 `npm run demo`가 매번 수행). 로컬 메모리 DB라 개발 서버를 재시작해도 초기화됩니다.
- `npm start`(운영 모드)는 `DATABASE_URL`이 없으면 일부러 시작하지 않습니다. 로컬 확인은 `npm run dev`로 합니다.
- **AI**: 키를 등록하지 않아 실제 AI 호출은 검증하지 못했습니다(어댑터·숫자 대조·대체 경로는 가짜 응답으로 테스트함). 키는 사용자가 직접 등록합니다.
- **배포**: 앱 `ax-talent-war-jieu`는 현재 `suspended` 상태의 정적 사이트로 확인됐고, 서버 앱 배포 설정 변경과 배포는 진행하지 않았습니다. 따라서 "배포 주소에서 3건 재현"은 미완료입니다.
- **PostgreSQL 접속**: 운영 DB(`pg`)에 실제로 접속해 보지 않았습니다. SQL은 PGlite(Postgres 호환)에서만 실행해 검증했습니다.
