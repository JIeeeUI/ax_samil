## 2. 업무모델과 데이터 설명
| 구분 | 내용 |
|---|---|
| 핵심 객체와 의미 | 제안 건(기안 PLAN-xxx / 전속계약), 인플루언서, 캠페인, 업무 시계, 확인 요청, 이력, 가정 세트, 하회 구간 |
| 핵심 관계와 연결 기준 | 주문의 `campaign_id`(last-click 7일)로 성과를 귀속. 같은 인플루언서의 모든 건을 연결 그룹으로 묶음(예: 혜인 PLAN-001·002·003 + 전속계약) |
| 상태·적용 시점·담당자·승인권한 | 상태: 재무 확인 대기 → 경로 판정됨 → 상신됨 → 승인/거절/보류 → 기한 경과/종결. 경로(위에서부터 적용): ① 전속계약 연 10억 원 초과 또는 현금 유출일이 하회 구간 안 → CEO/이사회 ② 건별 1천만 원 또는 기안 총액 1억 원 초과 → Masil 대표 + 그룹 보고 ③ 그 외 마케팅 전결. 결재 역할이 아닌 사람은 결정할 수 없음. 확인 요청 담당은 정보를 가진 부서, 회신 입력은 담당 + 결재 역할, 거절 후 재상신·종결은 마케팅 [교육용 가정, 원본이 보류 이후 담당을 정하지 않음] |
| 판단에 사용하는 규칙과 제약 | 공헌이익은 A05 기준(쿠폰·환불 이중 차감 없음). 표본 계열과 풀스케일 계열 절대금액 합산 차단. 가정은 모두 라벨(확정/벤치마크/가정)과 버전 표시 |
| 업무모델이 조회·계산·판단·승인·후속 작업을 연결하는 위치 | `src/app/service.ts`가 엔진(`src/engine/*`)·상태 규칙(`src/workflow/*`)·저장소(`src/store/*`)를 묶고, 화면(`app/*`)은 서비스만 호출 |
| 제공 BPMN에서 바꾼 것 | 해당 없음/[사용자 확인]. 원본의 승인 권한과 제약은 바꾸지 않았고, 에이전트는 경계를 넘는 결정을 자동 확정하지 않는다 |

## 3. 대표 실행 사례
| 사례 | 입력·조건 | 판단과 후속 처리 | 실행 증거 |
|---|---|---|---|
| 정상 | 업무 기준일 2026-07-01, 기안 25건 + 혜인 전속계약 | LOSS 6개 캠페인(CMP-0001·0002·0003·0012·0013·0014), 확정 전 집행 12건, 하회 구간 안 12건+전속계약 CEO/이사회(이사회 2026-07-06), 나머지 13건 대표+그룹 보고, 혜인·Ava Glow 연결 그룹 | `npm run demo -- normal`, `tests/demo/scenarios.test.ts` |
| 변경 (모의) | 혜인 측이 고정 피 인하 제안: 연 18억 / 연 9억 | 18억: CEO/이사회 유지, 위약금 재계산(갱신 직후 해지 9억 원). 9억: 대표 경로, 현금 유출일 확인 요청 생성 → 회신 8/10이면 CEO/이사회, 9/30이면 대표. 고정 피는 표본 순위와 곱하지 않아 "금액 판단 유보" 표시. 민감도: LC-0001 45일이면 CEO/이사회는 전속계약 1건 | `npm run demo -- change` |
| 정보 부족·거절 | 지급 일정 미확인 → 전속계약 보류 | 재무에 확인 요청(기한 있음) → 시계 7/14에 D-3 에스컬레이션 → 유리/불리/지연 회신 각각 재판정(유리 9/30: 하회 구간 밖, 불리 8/10: 안 — 28억은 어느 쪽이든 CEO/이사회) → CEO 거절 후 재상신. 기안 PLAN-001만 거절하면 "기안만 부결, 계약은 자동 갱신" 경고 | `npm run demo -- shortage` |

- 선택 설정(교육용 가정): `가정·기준값`에서 "1차/2차 결재"를 켜면 CEO/이사회 건에 대표 검토(1차)가 추가된다. 방법은 reproduce.md의 "1차/2차 결재와 확장 알림 계획표 켜기", 켠 상태의 동작은 시연이 아니라 합성 시계·합성 건 테스트(`tests/app/two-stage.test.ts`)로만 증명했고 기본 시연 3건에는 포함하지 않는다.
- 운영 중 AI의 역할: 상신 근거 요약, 확인 요청서 초안, 모의 회신 구조화(후보일 뿐 사람이 확인해야 반영). AI 문장 속 숫자·날짜는 엔진 값과 대조해 불일치하면 쓰지 않는다. 키가 없으면 템플릿(화면에 "AI 미사용"). 위치: `src/ai/*`. **실제 AI 호출은 키가 없어 검증하지 못했다.**
- 예상 효과의 산정과 가정: 금액 효과는 산정하지 않는다(표본·풀스케일 혼합 금지). 비용 가정 민감도: 음수 실질 ROAS 6건은 수수료 기준·환불 시 원가 회수 가정 조합에 관계없이 같다.
- 확인된 효과 / 모의·추정: 확인됨 — 계산·판정·상태 변경·알림. 모의 — CEO·대표 결정, 담당 부서(재무·계약 담당)·에이전시 회신, 통보 발송.
- 필수 확장이 쓰인 지점: 위 "정보 부족·거절"의 D-3 에스컬레이션, 기한 경과 자동 확정(시계 7/18) 기록. 다른 부서 영향 반영 지점: "정상"·"변경"의 하회 구간 → 경로 변경.
